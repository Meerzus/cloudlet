Cloudlet is a set of React components for the web. Each one has its own page in these docs: how to install it, how to use it and every prop it takes.

## Components

- [Toaster](/docs/components/toaster): a notification stack that collapses to a pill and opens into the Island. An npm package, `@cloudlet/toast`.
- [Color picker](/docs/components/color-picker): a swatch that opens into a full picker, and a palette of up to four colors. Installed as source with the shadcn CLI.
