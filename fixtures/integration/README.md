# Installed tarball consumers

These fixtures install one retained `npm pack` artifact in fresh temporary directories **outside** this workspace. The package is an extracted `node_modules/@cloudlet/toast` directory, never a workspace symlink or source alias. Node probes assert the resolution path and CSS export. Vite/Next read the package exports without a `paths`, bundler alias or `transpilePackages` override.

```sh
npm run pack:local
npm run test:consumers
# Or split the same pipeline:
node scripts/integration.mjs --tarball artifacts/integration/cloudlet-toast-1.2.0.tgz --prepare-only
node scripts/integration.mjs --tarball artifacts/integration/cloudlet-toast-1.2.0.tgz --browser-only
```

`--prepare-only` copies templates/shared files and the archive, refreshes only its local-file candidate version/integrity in each tracked consumer lockfile, then performs clean `npm ci`, `npm ls`, cold no-DOM Node import, strict TypeScript and production build. Transitive public dependency versions/integrities remain locked. Missing locks/entries fail by default. `--update-locks` bootstraps them intentionally; ordinary runs never resolve a new dependency tree. The runner uses the workspace npm CLI with its current Node executable to avoid a Volta fallback after changing into `/tmp`. It rejects a different npm version from the workspace `packageManager`.

Versions: Vite8.3.4 with React/React DOM18.2.0 and19.3.1; Next16.4.2 with installed React/React DOM19.3.1, dynamic App Router `/` and SSR Pages Router `/pages-smoke`. TypeScript7.0.2, Node types24.19.2, React18 types18.3.31/DOM18.3.7, React19 types19.3.0/DOM19.3.0. App Router may execute Next's bundled React; each browser audit records its actual `React.version`. Next fixtures use its supported webpack production build; the runtime library still uses the existing Vite build.

`--browser-only` starts localhost production servers at4280/4281/4282 and separate Vite19/18 development servers at4283/4284 and runs the installed Playwright1.64.1 Chromium/Firefox/WebKit projects. It verifies pre-mount delivery into the collapsed pill, empty SSR toast markup and hydration, explicit portal, `useCloudlet` ownership, two controllers with the same ID, actual custom background/foreground pixels via the computed shell path fill/color, RTL, the pill → Island morph, an arrival that keeps the current slide, the progress ring value, arrow-key slides, a real mouse swipe that dismisses the pill, the auto-opening command action, detach/arrival/remount, and tails/badge depth. StrictMode wraps consumers; production React does not replay development effects. A separate installed-tarball Vite19/18 development tests at4283/4284 proves actual replay (two effect setups/one cleanup) and successful Toaster detach/remount. These development servers have no strict CSP claim; all production CSP assertions stay on4280–4282. Existing React unit lifecycle tests provide further source-level regressions.

Every production HTML response enforces external styles plus `style-src-attr 'none'`, per-request style/script nonce, no `unsafe-inline` and no `unsafe-eval`. Vite passes its nonce via a server-injected meta element. Next16 Proxy forwards both CSP and nonce in request headers; App reads nonce inside its server boundary and Pages forwards it through SSR props and Document/NextScript. The controller stays inside the client wrapper. `securitypolicyviolation`, errors and unhandled rejections are recorded by an external production audit script and independently installed before bootstrap in Playwright. Tests exercise the animated runtime under the unchanged policy.

The React19 stress test repeats100 real Toaster detach/remount cycles per engine with persistent application-owned controllers, then explicitly disposes both controllers. At each detach, observed ResizeObserver targets/timeouts/intervals return to zero, and listeners on window/document/VisualViewport/fonts/MediaQueryList return to the first-detach baseline. It then checks idle RAF stability and sends100 arrivals with30 progress updates over approximately1second. This proves instrumented resource cleanup and bounded test behavior; it is not physical heap, CPU/battery, touch-device or minimum-browser-version certification. DOM listeners on collectible elements are outside the global listener probe. Screenshots are taken in Chromium only because the installed WebKit screenshot helper itself injects a nonce-less style.

Evidence is written to `artifacts/integration`: consumer directories/dependency versions/lockfile hashes/tarball hash in `consumers.json`, individual build/install/types/Node logs and lockfile copies, raw browser report and decoded runtime/stress audit summary. Temporary consumer directories remain available for inspection for the lifetime of the host's temporary storage. Regenerate them with the prepare command when removed. Nothing here publishes packages, hosts a registry, calls GitHub or deploys a site.
